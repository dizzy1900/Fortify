# Implementation status

Measured on August 4, 2026 against [PRODUCT_CONVERGENCE_NORTH_STAR.md](./PRODUCT_CONVERGENCE_NORTH_STAR.md). The M0-M12 domain foundation is now input to an ordered convergence programme; it is not proof that the current product is coherent, deployed, pilot-ready, or externally accepted.

## Current state

Fortify preserves a deterministic fictional Colorado renewal sandbox and a broad, locally validated M0-M12 domain foundation on normalized production architecture. The current convergence C0 slices add a distinct non-owner application role, separate migration/runtime connection requirements, transaction-local tenant/actor context, minimal opaque-credential tenant bootstrap, initial authenticated request/worker/webhook binding, real RLS filtering and leakage attacks under that role, a unique audit-chain link plus per-tenant advisory serialization, and atomic consumption for OIDC attempts, invitations, and one-use storage grants.

This is partial C0 local evidence. The executable inventory currently classifies 127 tenant-sensitive entry points: 116 are bound and 11 authenticated programme-analytics routes remain unbound. All three identity-bootstrap routes run global attempt/rate-limit work under the non-owner application role and tenant-owned invitation, membership, acceptance, and session work under transaction-local RLS. The bound access-control family minimizes its administrative response and rejects non-administrative membership authority after request-bound authentication. The bound storage family minimizes upload/finalization responses, rejects cross-tenant grant issue and redemption, and admits exactly one request-bound redemption winner. Membership invitation creation/revocation runs inside the authenticated tenant transaction, minimizes delivery fields, and rejects both non-administrative creation and cross-tenant revocation. Community, property-graph, document-intelligence, portfolio-import, governed-source, market-playbook, resilience-planning, funding/project-execution, independent-verification, integration, model-recognition, and recognition routes now use the request transaction, minimize their responses, reject cross-tenant reads/writes, and deny read-only mutation. Governed-source, target-profile, and funding-programme publication require distinct author, reviewer, and publisher identities; playbook and intervention approval require independent human reviewers; funding commitments and export instructions retain separate human decisions; verification credential/finding/certificate authority remains separated. Recognition delivery remains distinct from acceptance, reviewer access is exact-version and principal scoped, correspondence is preserved, and downstream outcome categories remain separate. Integration job replay appends an immediate successor, live-provider execution fails closed without credentials, and provider outputs remain candidate evidence. Model definitions, mappings, outputs, and commitments remain externally authored evidence with separate human authority. Project collaborator and external-verifier credentials now use the same opaque-secret hash as bootstrap and are proven valid, scoped, and revocable through actual request handlers. The primitive has not been exercised on selected managed PostgreSQL. The current schema remains 190 tables with 185 tenant RLS policies and 185 authorization resource classes; migrations 0027-0029 add role/grant/index/function controls rather than a new domain table.

The replacement north star makes California the initial production jurisdiction and expands the product into governed resilience investment, funding, independent verification, external-model mapping, explicit market commitments, and insurance-recognition outcomes. Those expanded capabilities are not implied by the existing renewal implementation or the local source workflow. No managed deployment, rights-cleared California portfolio or source snapshot, verified legal currentness, customer-approved source policy, real verifier, funding sponsor, model provider, insurer reviewer, backup restore, or paid pilot has been validated.
