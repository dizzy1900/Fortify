# Subprocessors

No production subprocessor is approved merely because an adapter exists. The deployment owner must publish the actual vendor, purpose, data categories, processing region, transfer mechanism, security terms, retention/deletion, incident notice, and effective date before customer data is processed.

Expected categories are managed application/container hosting, PostgreSQL, private object storage/KMS, OIDC, malware scanning, monitoring/error reporting, transactional email/Graph or Gmail, AMS/property systems, model providers, verifier systems, and backup storage. Local PGlite/SQLite fixtures and deterministic adapters are development dependencies, not production subprocessors.

Maintain a versioned register and customer-notice process. Reject undeclared telemetry and never send documents, personal data, credentials, or customer-confidential material to a provider outside the approved purpose and scope.
