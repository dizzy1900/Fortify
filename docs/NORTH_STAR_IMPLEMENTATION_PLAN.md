# Fortify north-star implementation plan

## Outcome

A specialist insurance broker can complete a credible five-minute renewal-evidence and reconsideration workflow offline, then show the same case to a read-only underwriter. The system produces real reviewable files and leaves a durable community record for next year.

## Vertical milestones

1. Foundation: operating contract, domain schema, deterministic seed, repository/storage boundaries, and institutional visual system.
2. Triage: public value proposition, role entry, portfolio priorities, community map, policy timeline, and persistent evidence record.
3. Notice to readiness: deterministic text/PDF-text extraction, human confirmation, versioned crosswalk, evidence room, visible readiness components, conflicts, and tasks.
4. Submission loop: editable letter, real PDF/ZIP generation, immutable audit history, underwriter clarification, broker response, and structured fictional outcome.
5. Persistence and reuse: maintenance calendar, year-over-year reuse, settings, reset, reports, role controls, and guided demo.
6. Proof: unit/integration/evaluation gates, full Playwright story, PDF render inspection, manual rubric, docs, security/limitations, and fresh-clone instructions.

## Acceptance bar

All routes are responsive and keyboard accessible; controls are live; data is deterministic and clearly fictional; unsupported claims are absent; generated artifacts are non-placeholder files; all local gates pass; known limitations are explicit.
