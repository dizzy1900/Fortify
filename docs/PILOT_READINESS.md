# Paid pilot readiness

This ledger prevents local implementation evidence from being presented as deployment, customer, programme, model-provider, verifier, or market validation.

| Gate                             | Required evidence                                                                                         | Current state                                                                                                                                        |
| -------------------------------- | --------------------------------------------------------------------------------------------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------- |
| Product coherence                | One authenticated case-first journey across the full lifecycle                                            | Not achieved; milestone workspaces remain separate                                                                                                   |
| Tenant security                  | Non-owner PostgreSQL role, request-bound RLS on every tenant entry point, concurrency and leakage attacks | In progress; local role/RLS/bootstrap primitive exists and 93/127 enumerated entry points are bound; 34 bindings and managed PostgreSQL proof remain |
| Identity                         | Managed OIDC, MFA policy, session/cookie attacks, revocation and recovery                                 | Adapter only; externally blocked                                                                                                                     |
| Data rights                      | Rights-cleared California portfolio and governed source policy                                            | Not available                                                                                                                                        |
| Pilot cohort                     | At least ten governed cases onboarded without code changes                                                | Not available                                                                                                                                        |
| Evidence custody                 | Private encrypted storage, malware scanning, exact-byte readback, retention and legal hold                | Local contracts only                                                                                                                                 |
| Workflow completion              | Import through maintenance and audit/ROI in one deployment                                                | Not achieved                                                                                                                                         |
| Verification                     | Authorized independent verifier and rights-cleared credential/method evidence                             | Not available                                                                                                                                        |
| Market interaction               | Authorized destination, immutable delivery receipt, normalized response                                   | Not available                                                                                                                                        |
| Programme interaction            | Real applicable programme rules, sponsor decision, milestone and approval/export                          | Not available                                                                                                                                        |
| Operations                       | Immutable deployment, monitoring/alerts, backup, PITR, fresh-target restore, incident exercise            | Not validated                                                                                                                                        |
| Accessibility and responsiveness | Full converted journey passes automated and inspected desktop/tablet/mobile gates                         | Existing milestone surfaces locally pass; unified product not yet built                                                                              |
| Performance                      | Pilot load profile and documented p95/error/queue results                                                 | Not measured                                                                                                                                         |
| Customer validation              | Design partner completes workflow and provides measured feedback                                          | Not available                                                                                                                                        |
| Commercial continuation          | Paid continuation or explicit continuation decision                                                       | Not available                                                                                                                                        |

No row may advance from unavailable or local evidence based on fixture output. Each pilot evidence item must identify organization, environment, source/rights, owner, date, exact artifact or receipt, limitations, and reviewer.
